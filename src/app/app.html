How to use the app

For numbered instructions on methods, work, assignments and handovers, open the Tutorials page.

  1. Add work. In Work queue, enter the method, required quantity, batch, samples and timepoint. Set sample readiness, the testing target and the reporting deadline.
  2. Assign work. Choose an analyst, date, start time, quantity and equipment. Resolve blocked items and review warnings before saving.
  3. Issue and print sheets. In Work sheets, select the date and analysts. Issue a saved version, then print it. Analysts use the printed sheets; they do not log in.
  4. Record progress. Open Assignments / progress from Work queue, or use an assignment's Progress button. Enter new successful and failed attempts from the returned sheet. Use Reject recorded output for a later failure; the earlier record stays visible and a repeat is created.
  5. Update assignments. Split unfinished work or assign a repeat from Problems & repeats. If an issued sheet is affected, issue and print a replacement.

Prototype assumptions

  • The laboratory must confirm step durations, hands-on timing, levels, qualifications and capacity. Changing an assigned quantity does not change the step durations.
  • Timing, readiness, qualification and booking problems raise warnings. Missing required fields, invalid quantities and incompatible equipment block saving.
  • Valid output counts successful replicates. Once all required output is recorded, the team leader marks the work checked, approved and reported separately. These statuses are not electronic signatures.
  • Each standard stores one current preparation date and time. Performed assignments retain their recorded recipe and standard context. Preparation bookings do not mark a standard ready. Separate batches, stock quantities and consumption are not tracked.
  • Data is saved only in this browser, not shared with other users. Changes in another tab prompt a reload. This does not provide reliable multi-user editing.

Not included

Analyst accounts, stock, prices, billing, live LabHQ / Outlook / Veeva integrations and automatic scheduling.

Use fictional data only. Reset clears work and bookings and restores the example definitions and resources. This prototype must not control real laboratory work.
